# **App Name**: Ardy Portfolio (erknt.net)

## Core Features:

- Static Content Presentation: Load and display all portfolio content, including projects, about details, skills, and certifications, from local static files (JSON or MDX) using Next.js Static Site Generation.
- Responsive Portfolio Showcase: Present a 'Featured Project' prominently and a grid of all projects with titles, descriptions, tech stacks, statuses, and links, fully responsive for various screen sizes.
- Professional Summary & Resume: Display a hero section with a brief introduction, professional summary, profile image, and provide a button to download the resume located at /public/resume.pdf.
- Categorized Skills & Certifications Display: Organize and display technical skills by category (e.g., Frontend, Backend, Database, Tools) and showcase certifications in a badge-style layout.
- Unified Single-Page Navigation: Implement a sticky top navigation bar with links to different sections (Home, Projects, About, Skills, Contact) for a seamless single-page user experience.
- Contact & Social Connectivity: Provide visible contact information, direct links to social media profiles (GitHub, LinkedIn), and an optional basic contact form UI for sending messages (no backend initially).

## Style Guidelines:

- Primary action color: A vibrant green (#00BF63) to symbolize growth and efficiency, used for interactive elements and key highlights.
- Background color: A very subtle, greenish off-white (#F3FCF6), created by heavily desaturating the primary action hue to provide a clean and modern canvas.
- Text color: A sophisticated dark gray (#333333) for high readability, offering a clean contrast against the light background.
- Secondary accent color: A bright yellow-green (#84ED48) to offer an additional contrasting visual highlight, enhancing dynamic elements.
- All text uses 'Inter', a grotesque-style sans-serif, for a modern, objective, and highly readable aesthetic across both headlines and body copy.
- Employ a minimalist set of clean, vector-based icons throughout the site, ensuring they complement the modern aesthetic without clutter, as seen in section headers and social links.
- Implement a clear, clean, and responsive single-page layout with generous spacing, soft shadows for depth, subtle rounded corners, and a sticky top navigation bar to maintain brand presence.
- Incorporate subtle hover animations on interactive elements like buttons and project cards to provide feedback and enhance the user experience without being distracting.
